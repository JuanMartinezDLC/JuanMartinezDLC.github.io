# 🍲 Restaurante Caldos de Gallina Calentano

Sitio web estático y responsivo

El objetivo principal fue crear una identidad digital para el negocio, permitiendo a los clientes consultar el menú, ver la galería de instalaciones y conocer las promociones vigentes, todo adaptado a dispositivos móviles y de escritorio.

## 🚀 Tecnologías Utilizadas
* **HTML5 Semántico:** Estructura limpia y organizada (Header, Main, Section, Footer).
* **CSS3 Puro:** Sin frameworks (No Bootstrap, No Tailwind).
    * **CSS Grid:** Utilizado para la maquetación del Menú y la Galería de fotos.
    * **Flexbox:** Utilizado para la navegación y alineación de elementos.
    * **Responsive Design:** Media queries para adaptar el diseño a celulares y computadoras.

## 📂 Estructura del Proyecto
* `index.html`: Página de inicio con banner principal y bienvenida.
* `menu.html`: Carta de alimentos con precios y descripciones.
* `galeria.html`: Mosaico de fotos del restaurante y platillos.
* `promociones.html`: Sección de ofertas y cupones.
* `css/style.css`: Hoja de estilos única con variables y diseño responsivo.
* `img/`: Carpeta de recursos gráficos.
